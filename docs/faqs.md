# FAQs

### Do I need a modpack?

Creative is vanilla — any client on the matching version joins. ATM11 needs the [pack](/docs/servers/atm11/), on
the exact version the server runs.

### A server shows offline on the homepage.

Probably is. The status check goes through a public ping API that occasionally hiccups, so try joining in-game
before assuming the worst.

### Which launcher?

Any. Prism Launcher and the Modrinth App are linked on each server's page because they make installing packs
painless; the official launcher works for the vanilla server.
