## Joining

**1. Add Instance**, top-left.
Copy an instance download link, or use vanila minecraft. Either will work. FYI, any instances on this page should be compatible with the server.
<InstanceTable serverId="creative" />
![Prism Launcher's main window, with the Add Instance button highlighted in the top-left corner](/img/prism/1-add-instance.png)

2. In **Prism Launcher**: *Add Instance → Import → From zip*, paste the link, **OK**.

![The Import pane of the New Instance window, with Import selected on the left and the pack link pasted into the direct-download field](/img/prism/2-paste-link.png)

3. Launch it, then *Multiplayer → Add Server* and paste the address above.
