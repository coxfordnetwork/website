# Coxford MC

Survival, creative, parkour and TNT run on a Paper server, Minecraft **{server.version}**. Everything runs
server-side, so there's nothing to install — *Multiplayer → Add Server*, paste the address, join.

Voxy distant terrain is supported server-side. On Windows/Linux, a Fabric {server.version} instance with
[Sodium](https://modrinth.com/mod/sodium), [Voxy](https://modrinth.com/mod/voxy) and
[LOD Server Support](https://modrinth.com/plugin/lod-server-support) gets it. Not on native macOS.
