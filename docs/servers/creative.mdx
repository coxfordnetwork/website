# Creative Vanilla Foreverworld

Creative building on a Paper server, Minecraft **{server.version}**. Vanilla — no modpack, nothing to install
beyond the game itself.

## Address

<Address address={server.address} />

## Quick join

1. Launch Minecraft **{server.version}** (the official launcher is fine; Prism or the Modrinth App if you prefer):

<Launchers />

2. *Multiplayer → Add Server*, paste the address above. Join.

Optional: Voxy distant terrain is supported server-side. On Windows/Linux, a Fabric {server.version} instance with
[Sodium](https://modrinth.com/mod/sodium), [Voxy](https://modrinth.com/mod/voxy) and
[LOD Server Support](https://modrinth.com/plugin/lod-server-support) gets it. Not on native macOS.

## Optional: the shader preset

Still nothing you need — the server is vanilla and plain Minecraft joins fine. This is a prepackaged Fabric
instance for anyone who wants shaders without building one: Iris and Sodium, Complementary Unbound, Better
Leaves, switched on out of the box.

Copy the link below, then in **Prism** *Add Instance → Import* and paste it. The **Modrinth App** takes the same
link.
