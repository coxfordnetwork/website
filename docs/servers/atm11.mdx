## Joining

1. Copy the instance link below.
2. In **Prism Launcher**: *Add Instance → Import → From zip*, paste the link, **OK**.
3. Launch it, then *Multiplayer → Add Server* and paste the address above.

<InstanceTable serverId="atm11" />

**Copy instance link** puts our own Prism instance straight on your clipboard — no storefront, no
installer, no account anywhere. Prism fetches the link and builds the instance from it, so one pasted URL
is the whole install. The dropdown beside it opens the pack's CurseForge page if you want the changelog or
the mod list.

It's a **MultiMC/Prism instance**, like the other two servers here — Prism and MultiMC read it, the
Modrinth App doesn't. It's a big download (~700 MB), so give it a few minutes on a slow connection.

You must be on **{server.instances[0].external.version}** exactly — the server refuses any other version on
connect. Give it a minute on first launch; it's a big pack, and 8 GB allocated to the instance is a good
place to start.
