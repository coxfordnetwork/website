# BetaCraft

Classic survival, with a few quality-of-life fixes. Skins are handled server-side, so they work without
anything on your end.

<Address server={server} />

## Install

Copy the link, paste it into Prism.

<InstanceTable serverId="beta173" />

**1. Add Instance**, top-left.

![Prism Launcher's main window, with the Add Instance button highlighted in the top-left corner](/img/prism/1-add-instance.png)

**2. Click Import, paste the link**, then **OK**.

![The Import pane of the New Instance window, with Import selected on the left and the pack link pasted into the direct-download field](/img/prism/3-paste-link.png)

Prism downloads the pack and builds the instance. Launch it, then *Multiplayer → Add Server* and paste the
address above.

That's the whole setup — the instance already has everything the server expects.
